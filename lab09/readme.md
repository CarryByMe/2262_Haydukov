### Задание 1 **(2)**
*Рассмотрим следующую программу.*
```
d = {'sep': ',' , 'end': '\n'}
l = ['Утопия', 14, 'Вселенная', 25]
print (l, d)
print (*l, d)
print (*l, *d)
print (*l, **d)
```
*Объясните результаты ее работы.*

*При устном ответе на вопросы вам потребуется рассказать, что такое "Утопия 14" и "Вселенная 25".*

**Ответ:**  
`*` распаковывает последовательность как позиционные аргументы, `**` — словарь как именованные аргументы.  
«Утопия 14» и «Вселенная 25» — это не единые объекты, а отдельные элементы списка: строка `'Утопия'` и число `14`, строка `'Вселенная'` и число `25`. При распаковке `print` выводит их рядом через пробел.

Вывод:
```
['Утопия', 14, 'Вселенная', 25] {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 sep end
Утопия,14,Вселенная,25
```
В последней строке `**d` передаёт в `print` параметры `sep=','` и `end='\n'`, поэтому элементы списка выводятся через запятую.

### Задание 6 **(2)**
*Запишите генератор в форме функции, который будет создавать последовательность по следующему правилу: если текущее число x четное, то следующее число равно x/2, иначе следующее число равно 3x + 1. Последовательность начинается с заданного числа n и заканчивается единицей.*

```
def gen(x):
    yield x
    while x != 1:
        if x % 2 == 0:
            x //= 2
        else:
            x = 3 * x + 1
        yield x

print(*gen(7))
```

### Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция? Что делает функция* **wrapper**? *Придумайте несколько примеров использования* **toint**.

**Ответ:**  
В `toint` передаётся вызываемый объект `fun`.  
`toint` возвращает функцию `wrapper`, которая запоминает `fun`.  
`wrapper` принимает позиционные аргументы `args`, преобразует их к `int` через `map(int, args)` и вызывает `fun` с целыми аргументами.

Примеры:
```
toint(pow)("2", "3")          # 8
toint(max)("3", "10", "7")    # 10
toint(lambda x, y: x * y)("4", "5")  # 20
```
