### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

```
def gen(x):
    yield x
    while x!=1:
        if x % 2 == 0:
            x //=2
        else:
            x = 3*x + 1

        yield x

print(*gen(7))  
```

###  Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция?*
*Что делает функция* **wrapper**?
*Придумайте несколько примеров использования* **toint**.

* В **toint** передаётся вызываемый объект fun: функция, лямбда или встроенная функция.
* **toint** возвращает новую функцию wrapper, то есть замыкание, которое запоминает fun.
* **wrapper** принимает произвольное число позиционных аргументов args, преобразует каждый аргумент к int через map(int, args) и вызывает fun с уже целыми аргументами. Результат fun возвращается как результат wrapper.
* Ключевые аргументы wrapper не принимает: в нём только *args.
* Если какой-то аргумент нельзя преобразовать к int, будет ошибка ValueError.
* Пример 1: toint(pow)("2", "3") вернёт 8.
* Пример 2: toint(max)("3", "10", "7") вернёт 10.
* Пример 3: toint(lambda x, y: x * y)("4", "5") вернёт 20.
